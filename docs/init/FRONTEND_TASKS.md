# フロントエンドタスク

## 前提

- 画面デザインの正はFigma
- 友達機能は今回やらない
- 認証は Googleログイン必須
- 一人モードはグループ作成/参加UIをスキップする
- 対象機能
  - ログイン
  - ユーザー名入力
  - モード選択
  - グループ作成
  - グループ参加
  - 猫選択
  - ホーム
  - 投稿
  - グループ一覧
  - 設定

5. APIエラーの共通処理を作る
6. 余裕があれば楽観更新を検討する

## フロントで吸収してよいもの

1. `AuthState`
2. `CurrentGroupState`
3. `OnboardingDraft`
4. `GroupMemberPreview`

理由:

- これらは画面側の一時状態や表示補助に近く、バックエンドの保存形式と分けて考えてよいため
- フロント都合で将来変わりやすいため

## バックエンドに返してもらう前提で進めるもの

1. `Profile`
2. `GroupSummary`
3. `InviteCode`
4. `Post`
5. `Post.user`
6. APIごとの input / output
7. 共通エラー型

理由:

- フロントでデータ整形の責務を持ちすぎないようにするため
- ホームや一覧画面の表示実装をシンプルにするため
